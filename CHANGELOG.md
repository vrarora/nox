# Changelog

## 0.2.0 (2026-10-28)

- Named **Nox**. App id `app.nox.launcher`. Earlier builds used `app.sill.launcher`, so this is a fresh install with fresh settings.
- App icon: an interlocking N with a quiet metallic finish. Full set in `brand/nox-icon/`, used on the LG Home tile, the splash screen and Nox's settings button, which brightens on focus.
- Splash screen: the mark centred on black.

## 0.1.x (2026-10-27)

First version, built and tested on one TV.

- App list with live HDMI input state, launch on OK, hold OK to reorder.
- Preview panel with each app's logo in its own colours over a soft, dithered glow.
- Ambient mode after 30 s: clock and weather, pixel shift every minute.
- Optional Nuvio continue-watching with QR device login, and an optional deep-link patch for the Nuvio TV app.
- Settings screen: ambient delay, sounds, hidden apps, Nuvio account. Settings can be pushed from a computer.
